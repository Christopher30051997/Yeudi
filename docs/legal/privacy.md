# Política de privacidad GemasGo

GemasGo usa datos mínimos para operar la cuenta: nombre, correo opcional, saldo, historial de anuncios, promociones y comprobantes. En esta versión frontend los datos se guardan localmente en el navegador mediante `localStorage`.

Para producción con backend real, estos datos deben almacenarse con cifrado, controles de acceso, auditoría y mecanismos de eliminación de cuenta.
