# Términos de uso GemasGo

Las GemasGo se obtienen viendo anuncios validados o comprándolas por medios aprobados. Las recompensas pueden retenerse si la IA antifraude detecta bots, automatizaciones, múltiples cuentas abusivas o manipulación del sistema de anuncios.

Las promociones de videos quedan sujetas a revisión administrativa antes de publicarse.
