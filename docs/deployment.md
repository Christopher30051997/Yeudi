# Despliegue

1. Publica los archivos estáticos en GitHub Pages, Netlify, Vercel o cualquier hosting HTTPS.
2. Configura `manifest.webmanifest` para PWA.
3. Sustituye `localStorage` por API backend cuando se requieran usuarios reales, pagos reales o anuncios reales.
4. Conecta proveedores externos para autenticación, pagos cripto, anuncios recompensados y almacenamiento de comprobantes.
